# 随身音乐

这是一个适用于 Chrome 和 Microsoft Edge 的浏览器扩展，用于搜索、试听和下载 MP3，并管理运动耳机、手表等设备的本地曲库。

支持歌曲宝和歌曲海两个音源，可将歌曲下载到电脑或已连接的设备，查看已有歌曲、读取封面、筛选和播放。

## 使用方式

1. 安装扩展后，点击浏览器工具栏中的扩展图标。
2. 选择音源，搜索歌曲，点击播放、下载到本地或发送到设备。
3. 通过 USB 连接设备，点击“添加设备”并授权音乐目录，即可查看和管理设备曲库。

设备需支持以磁盘方式传歌和 MP3 播放。首次使用时选择音乐目录，之后可复用已授权的目录。

## 本地开发

需要以下环境：

- Node.js 22.12.0 或更高版本
- pnpm 10 或更高版本
- Chrome 或 Microsoft Edge

安装依赖并启动监听构建：

```sh
nvm use
pnpm install
pnpm dev
```

开发产物输出到 `dist/`。打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，然后加载 `dist/` 目录。更新后需在扩展管理页点击“重新加载”，再重新打开随身音乐。
