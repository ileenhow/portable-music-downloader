# 本地测试步骤

这份清单用于实际 Chrome / Edge 与支持 U 盘传歌的设备测试，首个测试对象为韶音 S710。
面向其他手环、手表或耳机时，也需确认设备支持挂载为磁盘、通过音乐目录传歌及 MP3 播放。自动测试不代替实体设备测试。

1. 按 README 加载 `dist/`，确认扩展管理页没有红色错误，点击图标能打开“随身音乐”。
2. 确认左侧搜索与下载约占 1/4，右侧设备与曲库约占 3/4，同时可见；底部没有播放器工具栏。
3. 搜索“晴天 周杰伦”。研究时该搜索返回 20 个不同编号的版本；网站数据可能变化。
4. 搜索结果应只有“下载到本地”“下载到已连接设备”“播放”三个按钮。点“播放”，确认内容符合所选版本；再次点击可停止。
5. 没有连接设备时，设备下载按钮应不可用。点“下载到本地”，选择电脑测试文件夹，观察队列从解析、下载、校验到已保存。用其他播放器打开新 MP3，核对完整时长。
6. 再次下载同一个版本到同一目录，应该提示已存在；不同编号的同名版本应保存为带编号的不同文件。
7. 点右侧“添加设备”卡片，再点弹窗内的“手动选择目录”，先使用另一个可丢弃的测试目录。下载到设备，检查右侧封面、筛选、播放和文件信息；重新扫描后记录应保持。再下载一首到本地，应继续保存到步骤 5 的电脑目录，不改变当前设备或设备曲库。
8. 下载时点取消，再点继续；关闭/重新打开管理页，未完成项应暂停，点击继续后重新解析。
9. 测试删除时使用可丢弃的文件；取消确认不应删除文件，确认后应只删除该曲库项对应文件。
10. 添加两个测试目录，切换设备，确认曲库分别对应所选目录。测试设备重命名和移除记录；移除只删除目录记录及未完成设备任务，不应删除磁盘文件。重新打开页面时应保留设备列表；目录未授权时应提示重新授权。
11. 电脑目录测试通过后，用数据线连接 S710，进入 U 盘模式，点“添加设备”卡片，确认弹窗列表显示设备和容量。点设备的“连接”选择耳机音乐目录，绑定后主页面显示设备卡片；弹窗中的刷新不应弹选择器，重新打开时复用授权。重复单首设备下载测试。
12. 队列完成后安全弹出，切换耳机本地播放模式，确认新歌曲能播放。
13. 在没有写盘任务时拔出、重新接入设备，确认卡片连接状态更新，授权仍有效时自动读取曲库；需要授权时只在点击卡片后请求。设备断开后队列应保持暂停，重新接入不会自动写盘。同名同容量设备不应自动绑定到已有目录。

如需反馈，记录浏览器版本、操作步骤、歌曲编号和扩展管理页的错误。
不要把临时播放 token、Cookie 或含签名的完整音频 URL 放进公开反馈。

当前已完成本地自动检查及构建；实际扩展安装、网站会话、真实媒体下载及设备写盘留待此轮人工测试。
